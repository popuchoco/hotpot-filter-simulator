# 火鍋湯底過濾挑戰

一款以火鍋撈沫、撈油為主題的入門網頁遊戲。可先不限時練習辨認食材與工具，再挑戰不同關卡規則、湯底和事件。

## 玩法

- **一鍋大骨湯**：肉沫、芋頭／南瓜／番茄／馬鈴薯與淡黃色浮油漂在湯面。
- **練習與挑戰**：練習模式不限時、食材較少；挑戰模式有新手小鍋（50 秒）、家常火鍋（40 秒）和熱鬧滿鍋（35 秒）。
- **三種挑戰規則**：限時衝分、全清挑戰與無失誤挑戰。全清時限依關卡為新手 75 秒、家常 60 秒、熱鬧 55 秒。無失誤挑戰有 3 條命，每次主要目標選錯工具扣 1 命，命數歸零才會結束；時間到時仍有命數即可完成，零失誤會顯示「無失誤」，有失誤則顯示剩餘命數。錯用工具只扣分、增加湯汁損失與失誤，不會移除錯誤目標；全清只認正確撈起的食材。
- **關卡組合不同**：每關會調整肉沫、蔬菜、浮油數量；新手與滿鍋關亦採用不同蔬菜組合。
- **湯底與事件**：清湯、麻辣和味噌有不同湯色、流動及油花聚集速度；開局 6 秒後才開始第一次沸騰，之後依湯底節奏循環，推動食材並加快油花聚集。限時衝分與每日挑戰會分波補料；沸騰時會提前下一波，麻辣湯的辣椒片或味噌湯的豆渣顆粒會併入該波，每波最多 2 份，適合用細網處理。
- **分波與速度計分**：第 0 波保留開局份量；後續依時間或鍋中低量補料，鍋中食材達容量上限時會延後補料。新波食材從鍋緣漂入，淡入 0.6 秒期間不能撈。成功撈取間隔不超過 1.5 秒會累積連擊，倍率最高 1.5 倍；在下一波前清空目前鍋中食材可獲清波獎勵，並立即開始下一波。練習模式可在設定勾選「練習模式分波補料」，預設關閉。
- **分波清潔度**：每波新加入的食材質量都會加進本局初始質量，因此結算清潔度會以本局實際出現的全部食材計算。
- **三種工具有取捨**：普通湯匙接觸範圍大、撈油快，但帶走較多湯；有洞湯勺適合蔬菜和一般浮油；細網撈沫勺較精準、湯汁損失少，適合肉沫。撈取判定沿著畫出的勺面形狀，粒子圓碰到勺面就算命中；離勺心最近的命中粒子決定這次是否失誤，其他適用食材會一起撈起，不適用的連帶食材不扣命也不移除。
- **工具隨鍋縮放**：勺面依鍋子半徑等比縮放，手機與桌機維持相同的相對判定範圍；1920×1080 桌機尺寸沿用原有畫面比例。網址加上 `?debug=hit` 可顯示判定輪廓。
- **大塊食材與工具策略**：骨頭要用有洞湯勺撈兩次；連續使用普通湯匙會增加湯汁損失。
- **冷藏凝油預備**：限時挑戰每局可用一次，消耗 3 秒、效果維持 14 秒；將浮油以藍白色凝固效果呈現，改用細網撈取可獲加分。這是為了玩法簡化的縮時模擬，不代表實際冷藏只需數秒。
- **每日固定盤面**：同一天使用固定種子、食材配置和湯底；後續波次另用每日種子的亂數串流，不消耗物理亂數。選單顯示日期、湯底與種子尾碼，結算可複製連結，跨日開啟仍會標示原始盤面日期。
- **每日成就**：使用當日正確固定種子並成功撈取至少 8 次，才可解鎖「每日鍋友」；帶其他種子的分享盤仍可重玩，但不計成就。
- **結算回顧**：限時衝分會顯示波次數、最高連擊和清波次數。清潔度只平均本局實際出現的食材類別，以質量／面積記錄清除率；不存在的類別會顯示「本關無…」，若沒有任何清除目標則顯示 100%（無清除目標）。並顯示失誤率、剩餘食材、估算湯汁損失、關卡高分差距和與上次湯汁損失比較。
- **分數比較**：分波加入了連擊倍率和清波獎勵，更新後的分數不可與分波前的舊基線直接比較。
- **本機紀錄與解鎖**：各關最高分分開保存，可清除紀錄；完成指定條件會解鎖成就和鍋具外觀。資料都留在瀏覽器本機。
- **成就與結算**：「第一次開鍋」需成功撈取 5 次或遊玩滿 15 秒；無失誤挑戰只有時間到且零失誤才算完成，手動結束會標示「已中止」。限時衝分評語會同時參考分數與工具正確率。
- **即時回饋**：骨頭顯示還需要成功撈取幾次；連續正確撈取 5 次可在遊戲中即時解鎖成就，沸騰和骨頭裂開也有額外提示音。
- **全高遊戲版面**：遊戲畫面使用符合視窗高度的 grid，計時器與狀態列固定在上方，鍋子依剩餘空間維持正方形縮放，工具與暫停／結束按鈕固定在下方；手機橫向時操作區移到側欄。
- **鍵盤焦點操作**：開局會將焦點移到可用 Tab 選取的遊戲畫布；焦點在畫布時，方向鍵移動撈勺、Space／Enter 撈取。焦點在按鈕、選單、輸入欄、摘要或連結時，Space／Enter／方向鍵保留瀏覽器預設操作，不會誤觸撈取。遊戲畫面也提示 1／2／3 工具熱鍵，並提供高對比、減少動態效果與可選音效。
- **關卡建議**：首次遊玩建議從練習或新手小鍋開始；所有關卡仍可自由選擇，不以進度鎖住玩法。
- 暫停會同時停止倒數、沸騰事件和凝油效果；切到背景或離開頁面時會自動暫停，回到頁面後需手動繼續。調整視窗大小時，食材會依鍋心及鍋半徑等比換算位置，維持相對於鍋緣的位置。
- 練習模式的凝油有 25 秒冷卻時間。

## 程式結構

- `src/game.js`：選單、遊戲狀態、輸入、結果與本機資料；以原生 ES module 載入。
- `src/renderer.js`、`src/physics.js`：Canvas 繪製與不依賴 DOM 的粒子物理。
- `src/config.js`、`src/rules.js`、`src/rng.js`：共用設定、純規則函式與可重現亂數。
- `tools/`、`tests/`：本機靜態伺服器、Playwright 瀏覽器檢查、bot 評估與 Vitest 單元測試。

常用指令：

```bash
npm run serve       # 在 http://127.0.0.1:8765 預覽
npm run lint        # ESLint
npm test            # Vitest
npm run smoke       # 五種視窗尺寸的瀏覽器流程
npm run test:browser # 鍵盤焦點、背景暫停與縮放檢查
npm run eval:quick  # 小型 bot 評估
npm run eval:full   # cfgA–cfgG，每組三局
```

Playwright 會使用 `CHROME_PATH` 指定的 Chrome，或 `/usr/bin/google-chrome`；若兩者皆無，請先執行 `npx playwright-core install chromium`。

## GitHub Pages 部署

本遊戲是純前端 HTML、CSS 和 Canvas，無需建置步驟或後端。

1. 將專案檔案放在 GitHub repository 的根目錄（或 `/docs`）。
2. 在 **Settings → Pages** 選擇 `main` 分支和 `/ (root)`（或 `/docs`）。
3. 等待 GitHub Pages 部署完成，再開啟 GitHub 提供的網站網址。

## 本機預覽

在專案目錄執行：

```bash
npm run serve
```

GitHub Pages 仍直接提供原始 HTML、CSS 與 JavaScript，無需建置或 bundler。
