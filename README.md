# 火鍋湯底過濾挑戰

一款以火鍋撈沫、撈油為主題的入門網頁遊戲。可先不限時練習辨認食材與工具，再挑戰不同關卡規則、湯底和事件。

## 玩法

- **一鍋大骨湯**：肉沫、芋頭／南瓜／番茄／馬鈴薯與淡黃色浮油漂在湯面。
- **練習與挑戰**：練習模式不限時、食材較少；挑戰模式有新手小鍋（50 秒）、家常火鍋（40 秒）和熱鬧滿鍋（35 秒）。
- **三種挑戰規則**：限時衝分、全清挑戰（時間加長）與無失誤挑戰（錯用工具即結束）。
- **關卡組合不同**：每關會調整肉沫、蔬菜、浮油數量；新手與滿鍋關亦採用不同蔬菜組合。
- **湯底與事件**：清湯、麻辣和味噌有不同湯色、流動及油花聚集速度；沸騰湯流會定時推動食材並加快油花聚集。
- **三種工具有取捨**：普通湯匙接觸範圍大、撈油快，但帶走較多湯；有洞湯勺適合蔬菜和一般浮油；細網撈沫勺較精準、湯汁損失少，適合肉沫。
- **大塊食材與工具策略**：骨頭要用有洞湯勺撈兩次；連續使用普通湯匙會增加湯汁損失。
- **冷藏凝油預備**：限時挑戰每局可用一次，消耗 3 秒、效果維持 14 秒；將浮油以藍白色凝固效果呈現，改用細網撈取可獲加分。這是為了玩法簡化的縮時模擬，不代表實際冷藏只需數秒。
- **每日固定盤面**：同一天使用固定種子、食材配置和湯底；結算可複製連結，讓朋友挑戰相同盤面。
- **結算回顧**：清潔度以肉沫、蔬菜、浮油面積和骨頭各類清除率平均計算，油滴合併不會被誤算成已清理；並顯示每類清除率、失誤率、剩餘食材和估算湯汁損失。
- **本機紀錄與解鎖**：各關最高分分開保存，可清除紀錄；完成指定條件會解鎖成就和鍋具外觀。資料都留在瀏覽器本機。
- **無障礙操作**：鍵盤可選工具、移動撈勺、撈取和暫停；提供高對比、減少動態效果與可選音效。
- 暫停會同時停止倒數、沸騰事件和凝油效果；練習模式的凝油有 25 秒冷卻時間。

## GitHub Pages 部署

本遊戲是純前端 HTML、CSS 和 Canvas，無需建置步驟或後端。

1. 將專案檔案放在 GitHub repository 的根目錄（或 `/docs`）。
2. 在 **Settings → Pages** 選擇 `main` 分支和 `/ (root)`（或 `/docs`）。
3. 等待 GitHub Pages 部署完成，再開啟 GitHub 提供的網站網址。

## 本機預覽

可直接開啟 `index.html`，或在專案目錄執行：

```bash
npx serve .
# 或 python -m http.server
```
