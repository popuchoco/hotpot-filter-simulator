# 火鍋湯底過濾挑戰

同一鍋大骨湯風格的網頁小遊戲。時間內用對的工具把肉沫、蔬菜塊與浮油撈起來。

## 玩法

- **同一鍋**：大骨湯底，混有肉沫、蔬菜（芋頭／南瓜／番茄／馬鈴薯）與淡黃色半透明浮油。
- **倒數計時**：上方大時鐘，40 秒內盡量撈取。
- **三種道具**
  - 濾網：最適合肉沫，蔬菜也可以
  - 有洞湯勺：適合蔬菜與部分油
  - 普通湯匙：適合撈浮油（尤其大片）
- 用錯工具會漏掉並扣分。
- 成功撈到大塊聚集物有額外加分。
- 時間到後顯示詳細撈取成果統計。

浮油採用大骨湯風格（淡黃半透明），比純紅油更難辨識與聚集。

## 部署到 GitHub Pages

1. 將整個資料夾內容放到 GitHub repo 的根目錄（或 `/docs`）。
2. Settings → Pages → Source 選 main / root。
3. 即可透過 `https://<username>.github.io/<repo>/` 遊玩。

純前端（HTML + CSS + Canvas），無需後端。

## 本地預覽

直接開啟 `index.html`，或：

```bash
npx serve .
# 或 python -m http.server
```
